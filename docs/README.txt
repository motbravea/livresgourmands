# Documentation du projet

## Présentation

Ce dossier contient l’ensemble des documents de support du projet **livresgourmands.net**.

Il regroupe les éléments nécessaires pour comprendre, tester et valider le projet dans ses différentes étapes :
- modélisation UML
- API back-end
- base de données
- tests Postman
- conception visuelle
- intégration front-end React
- démonstration du fonctionnement

---

## Contenu du dossier

### 1. Captures d’écran Postman (`screenshots/`)

Ce dossier contient les captures d’écran des tests réalisés avec Postman lors de l’étape 2.

Ces captures démontrent :
- l’inscription d’un utilisateur
- la connexion avec génération d’un token JWT
- l’accès aux routes protégées
- la gestion des rôles
- les opérations CRUD sur les catégories
- les opérations CRUD sur les ouvrages

Ces éléments servent de preuve du bon fonctionnement de l’API REST.

---

### 2. Captures d’écran du front-end (`etape3-screenshots/`)

Ce dossier contient les captures d’écran du front-end React réalisé lors de l’étape 3.

Les captures présentent notamment :
- la page d’accueil
- le catalogue des ouvrages
- la fiche détail d’un ouvrage
- le panier dynamique
- la page de connexion
- le dashboard administrateur
- la gestion des ouvrages et catégories
- les versions responsive mobile/desktop

Ces captures permettent de démontrer l’intégration visuelle et fonctionnelle du front-end.

---

### 3. Dictionnaire des données (`data_dictionary.md`)

Ce document décrit la structure de la base de données.

Il contient :
- la liste des tables
- les colonnes de chaque table
- les types de données
- les clés primaires
- les clés étrangères
- les relations entre les entités

Ce fichier permet de comprendre l’organisation des données et les contraintes appliquées.

---

### 4. Dossier de conception Étape 3 (`dossier_conception_etape3.pdf`)

Ce document présente la conception visuelle du projet.

Il inclut :
- la description du projet
- les objectifs de l’étape 3
- l’identité visuelle choisie
- les couleurs principales
- le logo
- les choix typographiques
- les pages développées
- les choix UX/UI
- le responsive design
- l’intégration front-end / back-end
- les limites et améliorations possibles

Ce document correspond au dossier de conception demandé pour l’étape 3.

---

### 5. Liens de conception (`liens_design.md`)

Ce fichier contient les liens utiles liés à la conception et à la démonstration :

- lien Figma
- information concernant Adobe XD
- lien de la vidéo de démonstration

---

## Objectif de la documentation

Cette documentation a pour but de :
- faciliter la compréhension du projet
- démontrer le bon fonctionnement de l’API
- présenter la structure de la base de données
- justifier les choix de conception visuelle
- montrer l’intégration entre le front-end React et le back-end Node.js
- répondre aux exigences académiques du travail

---

## Conclusion

Le dossier `docs/` regroupe les documents nécessaires pour analyser, tester et valider le projet **livresgourmands.net**.

Il complète le code source et permet de présenter clairement le travail réalisé dans les différentes étapes du projet.
